本目录存放独立美术交接包和模拟器预览包的 Git 分卷，未覆盖项目原有代码。首版只开放蒙德，其他地区图片为后续预留。

## 还原

克隆包含本目录的分支，确保 `parts/` 下全部 8 个分卷都已下载，然后在本目录运行：

```sh
python3 restore.py
```

Windows 可运行 `py -3 restore.py`。脚本使用 Python 3 标准库，逐卷验证大小和 SHA-256，再验证还原后的 ZIP；成功后写入 `restored/`，不会覆盖已有文件。也可指定输出目录：`python3 restore.py --output-dir /path/to/output`。

| 原文件 | 分卷数 | 原始大小（字节） |
| --- | ---: | ---: |

| `Simulator-Art-Preview-v1.zip` | 2 | 22,890,623 |

每卷最大 20 MiB。完整文件和逐卷的 SHA-256、大小及顺序见 `manifest.json`。

## 范围与状态

美术包包含七国封面、38 张怪物母版及其 Lua 图元数据、原型参考、拟合和验证工具；蒙德首发使用其中 22 张怪物母版。纳塔封面已修正为陆地竞技场。新素材为待用户逐项审阅的候选；是否开放地区以包内 `release_config.lua` 为准。

预览包包含 45 张模拟器静态渲染截图与相关报告。它不代表接入正式游戏、完整战斗、动作或真机性能验收。该版本保留完整拟合结果，图元数量很高，性能优化留待后续。解压后先阅读各包内 README。
